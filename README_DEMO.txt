MISSÃO: ESTOQUE PERFEITO — DEMO / PLAYTEST
Versão 0.5.0-demo.1

COMO ABRIR

1. Extraia toda a pasta do arquivo ZIP antes de jogar.
2. Abra MissaoEstoque_Demo.exe com dois cliques.
3. Não mova nem apague os arquivos internos da pasta.
4. Use o Tutorial se esta for sua primeira vez.

CONTROLES

A / D ou setas esquerda/direita: mover
ESPAÇO: pular
E: interagir, pegar ou armazenar caixas
Q: usar scanner nas missões que exibem esse comando
TAB: consultar informações quando indicado
ESC: voltar ou abrir a pausa quando disponível
F11 ou ALT + ENTER: alternar entre janela e tela cheia

FEEDBACK

Conte se os controles e objetivos ficaram claros, qual fase foi mais
divertida, onde encontrou dificuldades e qualquer bug observado.
Se houver um erro, envie um print e o arquivo crash.log localizado em:
%%LOCALAPPDATA%%\MissaoEstoqueDemo\logs\

O progresso e as configurações ficam em:
%%LOCALAPPDATA%%\MissaoEstoqueDemo\save_demo.json

Esta demo não envia telemetria nem dados pela internet.

AVISOS DO WINDOWS

Por não possuir assinatura digital, o Windows SmartScreen pode exibir
um aviso. Builds PyInstaller também podem ocasionar falso positivo em
alguns antivírus. O jogo não requer permissão de administrador.
